# Zadanie Rekrutacyjne – Angular 17

## Cel zadania

Stworzenie aplikacji do zarządzania użytkownikami.

Możesz skorzystać z internetu, ale bez **żadnych chatów AI**, stara szkoła - dokumentacja, stack, github itp!

---

## Główne założenia

1. Wyświetlenie listy użytkowników.
  - Lista powinna być **posortowana po ID roli**.
2. Dodanie możliwości **dodawania nowego użytkownika z przypisaną rolą**.
  - Użyj dowolnego podejścia: `FormBuilder`, `ngModel`, `ReactiveForms` itp.
3. Zastosowanie **nowych funkcjonalności Angulara 17**:
  - Control Flow (`@if`, `@for`)
  - Signals
  - `@defer`
4. Stworzenie własnej **dyrektywy do anonimizacji danych**:
  - Maskowanie: nazwiska, adresu e-mail, numeru telefonu
5. Prosty layout oparty na **Flexbox lub CSS Grid** – wybór dowolny
6. Stylowanie przy użyciu **SCSS** z zastosowaniem metodologii **BEM**
7. Użycie **RxJS** do obsługi mockowanych danych (np. `of`, `delay`, `throwError` itd.)

---

## Opcjonalne rozszerzenia

1. Własna konfiguracja `tsconfig.json`
2. Dodanie animacji przy użyciu **Angular Animations**
3. Obsługa błędów w strumieniach RxJS (`catchError`, `retry`, itp.)
4. Podstawowe dostosowanie aplikacji do **WCAG 2.1 poziom A**
